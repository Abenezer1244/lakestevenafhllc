Every canonical tag, og:url, og:image, twitter:image, JSON-LD `@id`/`url`/`image`, and all 5 sitemap URLs point at a host that fails the TLS handshake for every browser, crawler, and social scraper (verified via OpenSSL: cert SAN contains only `lakestevensafh.com`). Fixing this one thing improves Technical, Schema, Sitemap, GEO, Local, and Content scores simultaneously.

## Prioritized Action Plan

### CRITICAL — fix immediately

**C1. Resolve the www/apex domain split (root cause of ~half the findings).**
Fastest path: make **apex** the canonical host.
1. Replace `https://www.lakestevensafh.com` → `https://lakestevensafh.com` in every `canonical`, `og:url`, `og:image`, `twitter:image`, and JSON-LD `@id`/`url`/`image` across all 5 pages, and in `sitemap.xml`.
2. In Vercel project settings, add `www.lakestevensafh.com` as a project domain so Vercel issues a valid cert for it, and set it to 308-redirect to the apex. (Currently `http://www` 308-redirects into the broken `https://www` — a dead end.)

**C2. Deploy the uncommitted performance fix.** The live homepage still autoplays a **21MB hero video** — 96% of a 16MB page, the sole cause of LCP 4.7s (Poor) and 840ms TBT (high INP risk). The working tree already replaces it with a 238KB `g10.webp`; commit and deploy, then delete `videos/hero.mp4`.

**C3. Verify the DSHS license number before deploying it.** Live site shows `License No. [pending]`; the uncommitted working copy contains `759247`, which has no verifiable provenance in the repo (an earlier value was formatted like an EIN). Cross-check against the WA DSHS/ALTSA AFH provider registry before publishing — an unverified license number on a YMYL care site is worse than the placeholder. Once verified, also add it to JSON-LD as an `identifier` and link the DSHS lookup so families can self-verify.

**C4. Replace the fabricated Google review link.** `placeid=ChIJLakeStevensAFH` is not a real Place ID — the review button silently fails. Claim/verify the Google Business Profile (primary category: **"Assisted living facility"**; avoid "Nursing home"), then use the real review short-link from the GBP dashboard.
